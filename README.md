# RailPulse

> An authentic Network Rail departure board simulator with live local weather integration.

## 🚂 Overview

**RailPulse** recreates the classic passenger information display systems (PIDS) found across UK train stations. Designed to mimic iconic orange/amber matrix boards, it delivers realistic station departures while pulling in live weather conditions to complete the station-platform atmosphere.

## ✨ Features

* 📺 **Authentic Station UI:** Mimics the high-contrast aesthetic and layout of traditional Network Rail departure boards.
* 🌦️ **Live Weather Integration:** Fetches and displays real-time weather conditions for the station's location.
* 🚉 **Station Customization:** Configure or simulate departures for various stations.

## 🛠 Tech Stack

* **Language:** TypeScript
* **UI/UX:** HTML5 / CSS3 / JavaScript
* **Weather API:** Integrated live weather data provider
